适合新手按阶段推进：先把网络、Linux、Web 基础打稳，再进入 CTF 专题、漏洞复现和个人项目沉淀。

  1. 01

    基础环境与网络常识

    准备虚拟机、编辑器、浏览器插件和抓包代理，理解 TCP/IP、DNS、HTTP、命令行、权限和日志。

    Linux HTTP
  2. 02

    Web 安全入门

    学习 OWASP Top 10、SQL 注入、XSS、SSRF、文件上传、反序列化和鉴权缺陷，配合靶场逐类练习。

    Web Burp
  3. 03

    CTF 专题刷题

    按 Web、Crypto、Reverse、Pwn、Misc 分类刷题，记录 payload、脚本、卡点和赛后复盘。

    CTF Writeup
  4. 04

    漏洞复现与攻防实践

    从公开漏洞通告出发，搭建环境、复现影响、理解补丁差异，再整理修复方案。

    CVE 复现
  5. 05

    项目沉淀与输出

    做一个安全资讯站、工具箱、靶场记录、漏洞复现知识库或个人博客，把学习过程变成作品。

    项目 博客
